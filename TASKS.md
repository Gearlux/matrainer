- [ ] **The four framework-needing docs pages have no runnable twin** @small @docs — the README split into ten `docs/<topic>.md` pages on 2026-10-28 and the aisland rule wants each topic to have an example CI runs and that asserts what it demonstrates. - [ ] **Bumping `CLEARML_SERVER_VERSION` needs a digest refresh, and nothing checks that** @low @maintenance — `matrainer/services/clearml_service.py` pins the tag AND `COMPOSE_SHA256`; changing one without the other fails at `aisland clearml start` with a checksum mismatch, which is safe but late. A test cannot fetch (offline CI), so the options are a refresh command that prints the new value or a check behind a network guard. @2026-10-25
- [ ] **A run-name suffix for every tracker** @small @feature — a Melody tracker shipped by a consuming project adds `run_name_suffix` (`name` | `counter` | `none`) at run start because its platform refuses a second run of one name; a config that pins `run_name` reruns into the same name on the other backends too (CSV/TensorBoard directories reused, MLflow runs that share one name). Lift the setting into `Tracker` when a second backend needs it; `counter` then needs a per-backend "names already used" query. @2026-10-14
- [ ] **Model packages: settings fixed at packaging time** @small @feature — `PackageModel` takes the graph as it is on disk; a checkpoint trained before an edit of that graph (a picture size changed since) can only be packaged with the drift and corrected by every caller's `ModelPackage.overrides`. Measured 2026-10-12: an option-A detector packaged after its picture width changed 1024 → 504 scored 1110 accurate / 104 missed on 81 captures, 1158 / 73 with `overrides: {picture.image.op.width: 1024, picture.image.op.height: 1024}`. A `PackageModel.overrides` written into `package.yaml` and applied before the caller's would let the package carry the training-time settings. @2026-10-12
- [ ] **Model packages: one file to move** @low @feature — a package is a folder (user choice 2026-10-12); copying or uploading it is one `zip`/`tar` away, and a tracker's `log_artifact` takes a single file. Add a transport form (`<package>.zip`, opened into a cache on first use by `ModelPackage`) when a package must travel through a tracker or a model registry. @2026-10-12

- [ ] **Read a sweep back from the trackers that are not MLflow or CSV** @low — `matrainer.sweep.report.QUERYABLE` is `("mlflow", "csv")` (`matrainer/sweep/report.py:66`); `collect()` (`report.py:170`) dispatches on the tracker name and, for the rest, prints an open-it-yourself hint (`tensorboard --logdir ...`, `aim up --repo ...`) instead of a table. `aim` is genuinely queryable (`Repo.iter_runs()`, with the indexing lag matrainer's AGENTS documents) and `tensorboard` is readable through `EventAccumulator`; an offline ClearML task and W&B are not, without a server.
